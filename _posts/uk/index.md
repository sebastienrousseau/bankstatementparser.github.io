**Аналізатор банківських виписок** — це бібліотека Python із відкритим вихідним кодом, яка аналізує банківські виписки з шести форматів (CAMT.053, PAIN.001, CSV, OFX, QFX, MT940) у структуровані pandas DataFrames. Уся обробка виконується локально — відсутність мережевих викликів, детермінований вихід і автоматичне редагування ідентифікаційної інформації.

## Розпочніть за лічені секунди

```bash
pip install bankstatementparser
```

```python
from bankstatementparser import create_parser, detect_statement_format

fmt = detect_statement_format("statement.xml")
parser = create_parser("statement.xml", fmt)
df = parser.parse()  # pandas DataFrame, ready to use
```

## Створено для переходу на ISO 20022

SWIFT встановив чіткі терміни: усі фінансові установи мають отримати CAMT.053 до листопада 2027 року, а MT940/MT942/MT950 буде повністю припинено до листопада 2028 року. Парсер банківських виписок обробляє застарілий формат MT940 і сучасний формат ISO 20022 (CAMT.053, PAIN.001) в єдиному API, тож ваш конвеєр аналізу працює під час переходу. і далі.

- **27 000+ транзакцій за секунду** для аналізу CAMT.053

## Чому аналізатор банківських виписок?

- **Автоматичне визначення формату**:`detect_statement_format()`автоматично визначає файли та`create_parser()`повертає правильний аналізатор.
- **Privacy First**: редагування ідентифікаційної інформації ввімкнено за умовчанням. Конфіденційні поля (імена, IBAN, адреси) маскуються у вихідних даних CLI. Підключитися за допомогою`--show-pii`коли потрібно.
- **Виробнича готовність**: безпечне введення ZIP-файлів (захист від бомб, відхилення зашифрованого входу), перевірка введених даних і запобігання проходженню шляху.
- **Гнучкий вихід**: експортуйте в CSV, JSON, Excel або конвертуйте в Polars DataFrames.
- **Паралельна обробка**: аналіз кількох файлів одночасно`parse_files_parallel()`.


## Створено для виробництва

Парсер банківських виписок розроблений для команд казначейства, розробників фінансових технологій і спеціалістів із відповідності, які обробляють конфіденційні фінансові дані. Бібліотека використовується в конвеєрах міграції з MT940 на CAMT, автоматизованих системах узгодження та робочих процесах регуляторного аудиту в фінансових установах.
