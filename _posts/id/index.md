**Bank Statement Parser** adalah pustaka Python sumber terbuka yang mengurai laporan bank dari enam format (CAMT.053, PAIN.001, CSV, OFX, QFX, MT940) ke dalam panda DataFrames terstruktur. Semua pemrosesan berjalan secara lokal — tanpa panggilan jaringan, keluaran deterministik, dan redaksi PII otomatis.

## Memulai dalam Hitungan Detik

```bash
pip install bankstatementparser
```

```python
from bankstatementparser import create_parser, detect_statement_format

fmt = detect_statement_format("statement.xml")
parser = create_parser("statement.xml", fmt)
df = parser.parse()  # pandas DataFrame, ready to use
```

## Satu Perpustakaan, Enam Format

Parsing CAMT.053, PAIN.001, CSV, OFX, QFX, dan MT940 ke dalam panda DataFrames terstruktur dengan satu API terpadu. Tidak perlu menginstal paket terpisah untuk setiap format.

| Fitur | Pengurai Laporan Bank | OSS format tunggal (mt940, ofxparse) | SaaS (Ocrolus, Parseur) |
|---|---|---|---|
| Format yang didukung | 6, API terpadu | masing-masing 1 | Banyak (melalui OCR) |
| Privasi data | 100% lokal, tanpa panggilan jaringan | 100% lokal | Data dikirim secara eksternal |
| Biaya | Gratis, Apache 2.0 | Bebas | $49-$1.000+/bln |
| redaksi PII | Bawaan, aktif secara default | TIDAK | Bervariasi |
| Mengalir | Memori yang terbatas | TIDAK | T/A |
| Keamanan ZIP | Pengerasan bawaan | TIDAK | T/A |
| Deduplikasi | Terintegrasi dengan skor kepercayaan diri | TIDAK | Beberapa |

## Dibangun untuk Migrasi ISO 20022

SWIFT telah menetapkan tenggat waktu yang pasti: semua lembaga keuangan harus menerima CAMT.053 paling lambat bulan November 2027, dan MT940/MT942/MT950 akan dihentikan sepenuhnya pada bulan November 2028. Bank Statement Parser menangani MT940 lama dan format ISO 20022 modern (CAMT.053, PAIN.001) dalam satu API, sehingga saluran penguraian Anda berfungsi selama masa transisi dan seterusnya.

## Pertunjukan

- **27.000+ transaksi/detik** untuk penguraian CAMT.053
- **52.000+ transaksi/detik** untuk penguraian PAIN.001
- **< 2 ms** waktu untuk hasil pertama
- **Memori konstan** dari 1K hingga 50K+ transaksi melalui streaming
- **467 pengujian** dengan cakupan cabang 100% di Python 3.9 hingga 3.14

## Mengapa Pengurai Laporan Bank?

- **Format Deteksi Otomatis**:`detect_statement_format()`mengidentifikasi file secara otomatis dan`create_parser()`mengembalikan parser yang tepat.
- **Privasi Pertama**: Redaksi PII diaktifkan secara default. Bidang sensitif (nama, IBAN, alamat) disamarkan dalam keluaran CLI. Ikut serta dengan`--show-pii`bila diperlukan.
- **Produksi Siap**: Penyerapan ZIP yang aman (perlindungan bom, penolakan entri terenkripsi), validasi masukan, dan pencegahan penjelajahan jalur.
- **Output Fleksibel**: Ekspor ke CSV, JSON, Excel, atau konversi ke Polars DataFrames.
- **Pemrosesan Paralel**: Mengurai beberapa file secara bersamaan`parse_files_parallel()`.


## Dibangun untuk Produksi

Pengurai Laporan Bank dirancang untuk tim perbendaharaan, pengembang fintech, dan petugas kepatuhan yang memproses data keuangan sensitif. Pustaka ini digunakan dalam jalur migrasi MT940 ke CAMT, sistem rekonsiliasi otomatis, dan alur kerja audit peraturan di seluruh lembaga keuangan.

- **467 pengujian** dengan cakupan cabang 100% di Python 3.9 hingga 3.14
- **Dependensi yang dikunci hash SHA-256** dengan CycloneDX SBOM untuk setiap rilis
- **Output deterministik** — input identik menghasilkan hasil byte-identik, setiap kali dijalankan
- **Berlisensi Apache 2.0** — digunakan secara bebas dalam sistem komersial dan internal
