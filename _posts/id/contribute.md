Kami menyambut baik kontribusi dari pengembang, penulis teknis, dan siapa pun yang tertarik untuk meningkatkan penguraian laporan bank untuk komunitas keuangan.

## Cara Berkontribusi

### Laporkan Masalah

Menemukan bug atau memiliki permintaan fitur? [Buka terbitan di GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). Harap sertakan:

- Penjelasan yang jelas tentang masalah atau saran.
- Langkah-langkah untuk mereproduksi (untuk bug).
- Versi Python dan sistem operasi Anda.

### Kirim Kode

1. Cabangkan [repositori](https://github.com/sebastienrousseau/bankstatementparser).
2. Buat cabang fitur (`git checkout -b feature/your-feature`).
3. Tulis tes untuk perubahan Anda (kami memerlukan cakupan cabang 100%).
4. Jalankan rangkaian pengujian:`pytest`.
5. Ajukan pull request dengan deskripsi yang jelas.

### Tingkatkan Dokumentasi

Perbaikan dokumentasi selalu diterima. Anda dapat:

- Memperbaiki kesalahan ketik atau memperjelas konten yang ada.
- Tambahkan contoh penggunaan baru ke [direktori contoh](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- Tingkatkan docstrings dalam kode sumber.

## Pengaturan Pengembangan

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## Standar Kode

- Semua kode harus lolos`ruff`linting dan`mypy`pengecekan tipe.
- Semua komitmen harus ditandatangani.
- Semua permintaan penarikan harus mempertahankan cakupan cabang 100%.
- Ikuti gaya dan pola kode yang ada.
