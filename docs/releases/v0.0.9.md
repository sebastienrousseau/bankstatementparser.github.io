## Highlights ⭐️

* **Search engines see only real pages**: `sitemap.xml` now lists only indexable pages that are their own canonical, and every internal link uses the canonical URL instead of `/page/index.html`.
* **Moved pages redirect**: `/faq/` and `/contribute/` forward to `/faqs/` and `/contributing/`, and missing URLs get the site's own 404 page instead of the GitHub Pages default.
* **Built with ssg 0.0.72**: local builds, the release workflow and the devcontainer use the latest `ssg`, and CI now holds every Python function to the complexity ceilings.
