## كيفية المساهمة

### الإبلاغ عن المشكلات

وجدت خطأ أو لديك طلب الميزة؟ [افتح مشكلة على GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). يرجى تضمين:

- وصف واضح للمشكلة أو الاقتراح.
- خطوات التكاثر (للأخطاء).
- إصدار بايثون ونظام التشغيل الخاص بك.

### إرسال الرمز

1. شوكة [المستودع](https://github.com/sebastienrousseau/bankstatementparser).
2. إنشاء فرع الميزة (`git checkout -b feature/your-feature`).
3. قم بكتابة اختبارات لتغييراتك (نطلب تغطية فرعية بنسبة 100%).
4. قم بتشغيل مجموعة الاختبار:`pytest`.
5. أرسل طلب سحب مع وصف واضح.

### تحسين التوثيق

نرحب دائمًا بتحسينات التوثيق. أنت تستطيع:

- إصلاح الأخطاء المطبعية أو توضيح المحتوى الموجود.
- إضافة أمثلة استخدام جديدة إلى [دليل الأمثلة](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- تحسين سلاسل المستندات في الكود المصدري.

## إعداد التطوير

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## معايير الكود

- يجب أن تمر جميع التعليمات البرمجية`ruff`البطانة و`mypy`فحص النوع.
- يجب التوقيع على جميع الالتزامات.
- يجب أن تحافظ جميع طلبات السحب على تغطية فرعية بنسبة 100%.
- اتبع نمط وأنماط التعليمات البرمجية الموجودة.
