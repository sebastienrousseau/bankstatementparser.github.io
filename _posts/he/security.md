**בקצרה:** Bank Statement Parser מעבד את כל הנתונים מקומית, עורך PII כברירת מחדל, מקשיח ניתוח XML נגד התקפות XXE, מריץ LLMs מקומית דרך Ollama, ומגיע עם תלויות נעולות ב-SHA-256 hash ו-CycloneDX SBOM.

## אבטחה מהעיצוב

Bank Statement Parser בנוי לעיבוד נתונים פיננסיים רגישים. כל החלטת עיצוב מעדיפה אבטחה, פרטיות וביקורתיות.

## אפס תלות בענן

כל העיבוד מתרחש מקומית בתוך ה-runtime שלך. המנתחים הדטרמיניסטיים מבצעים אפס שיחות רשת. ה-pipeline ההיברידי ל-PDF משתמש ב-Ollama להסקת LLM מקומית — שום נתון לא נשלח ל-APIs בענן. מנתחי XML מוגדרים במפורש עם `no_network=True`, `resolve_entities=False` ו-`load_dtd=False` למניעת כל גישה יוצאת.

## עריכת PII

מידע אישי מזהה (שמות, IBANs, כתובות דואר) נערך אוטומטית בפלט CLI ובמצב streaming. זה פועל כברירת מחדל.

- **CLI**: שדות רגישים מופיעים כ-`***REDACTED***`
- **streaming**: `parse_streaming(redact_pii=True)` (ברירת מחדל)
- **ייצוא**: CSV/JSON/Excel שומרים נתונים מלאים לעיבוד במורד הזרם
- **הפעלה**: השתמש ב-`--show-pii` או `redact_pii=False` כשאתה צריך פלט לא ערוך

## אבטחת XML (הגנת XXE)

כל ניתוח XML משתמש ב-`lxml` עם הגדרות מוקשחות:

- `resolve_entities=False` -- מונע התקפות הרחבת ישויות XML
- `no_network=True` -- חוסם כל גישת רשת יוצאת מהמנתח
- `load_dtd=False` -- מונע התקפות מבוססות DTD
- הסרת namespaces לפני עיבוד -- מטפל בכל וריאנט של CAMT.053 בבטחה

## אבטחת ארכיוני ZIP

`iter_secure_xml_entries()` מאמת כל חבר ZIP לפני חילוץ:

- **תקרת גודל ערך**: 10 MB לערך (ניתן להגדרה)
- **תקרת גודל כוללת**: 50 MB לא-דחוס כולל (ניתן להגדרה)
- **מגבלת יחס דחיסה**: ברירת מחדל 100:1 -- מזהה פצצות ZIP
- **דחיית ערכים מוצפנים**: ערכים מוצפנים מדולגים עם אזהרה
- **ללא כתיבה לדיסק**: בתי XML עוברים ישירות למנתח דרך `from_bytes()`

## מניעת חציית נתיבים

אימות קלט חוסם נתיבי קבצים מסוכנים:

- בתי null, דפוסי חציית תיקיות (`../`) ו-symlinks נדחים
- אימות סיומות קובץ מול פורמטים צפויים
- מגבלות גודל קובץ (ברירת מחדל 100 MB, ניתן להגדרה)

## אימות יתרה (כלל הזהב)

כל חילוץ PDF מאומת באמצעות המשוואה: `opening balance + credits − debits == closing balance`. תוצאות מתויגות כ-VERIFIED, DISCREPANCY או FAILED. אי-התאמות ניתנות לסקירה אינטראקטיבית עם `--type review`.

## פלט דטרמיניסטי

עבור פורמטים מובנים (CAMT, PAIN.001, CSV, OFX, QFX, MT940), בהינתן אותו קובץ קלט, המנתח מייצר פלט זהה בתים בכל הרצה. ללא אקראיות, ללא הסקת מודל, ללא דגימה היוריסטית. זה קריטי עבור:

- **שחזוריות ביקורת**: הרץ את אותו קובץ פעמיים והשווה את הפלט
- **ציות רגולטורי**: הדגמת עיבוד עקבי
- **אימות CI**: 718 בדיקות אוכפות דטרמיניזם עם כיסוי branches של 100%

## אבטחת שרשרת אספקה

- **תלויות נעולות ב-SHA-256 hash**: לכל חבילה ב-`poetry.lock` יש hashes מאומתים
- **CycloneDX SBOM**: כל גרסה כוללת Software Bill of Materials
- **מקור בנייה של GitHub**: אישור שמקשר כל artifact ל-commit המקור שלו
- **commits חתומים**: כל ה-commits חתומים ב-SSH ומאומתים ב-CI
- **אימות תלויות**: `scripts/verify_locked_hashes.py` מאמת את כל ה-hashes מקומית

## אימות מקומי

python -m pytest                          # 718 tests, 100% branch coverage
python scripts/verify_locked_hashes.py    # SHA-256 hash verification
