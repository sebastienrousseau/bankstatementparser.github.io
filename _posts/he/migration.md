**TL;DR:** SWIFT תוציא משימוש את MT940 עד נובמבר 2028. מנתח חשבונות בנק מטפל גם ב-MT940 וגם ב-CAMT.053 עם API יחיד, כך שצינור הניתוח שלך עובד במהלך המעבר ואחריו.

## מדוע ההגירה הזו חשובה

SWIFT פורשת פורמטים של הודעות MT מדור קודם לטובת תקן ISO 20022 העשיר יותר. עבור צוותי האוצר והפיננסים, פירוש הדבר שצינורות עיבוד דפי הבנק שלך חייבים להתפתח מ-MT940 ל-CAMT.053 לפני המועדים הקשים.

## ציר זמן של העברת SWIFT

| תַאֲרִיך | צִיוּן דֶרֶך | פְּגִיעָה |
|---|---|---|
| **נובמבר 2025** | דו-קיום MT-to-MX הסתיים עבור תשלומים חוצי גבולות | הודעות PACS הן כעת ISO 20022 בלבד |
| **נובמבר 2026** | כתובות מובנות/היברידיות חובה; MT101 ריבוי הוראה נדחתה; ניהול תיקים שלב 1 | פורמטים של כתובות חייבים להתאים; חלק מהודעות MT יידחו |
| **סוף 2026** | ההצטרפות מתחילה לקבלת CAMT.052/.053/.054 | מוסדות פיננסיים יכולים להתחיל לקבל הצהרות ISO מקוריות |
| **נובמבר 2027** | כל FIs חייבים לקבל CAMT.053 באופן מקורי | SWIFT מפסיקה להמיר פורמט MT ל-ISO; המערכות שלך חייבות לנתח את CAMT ישירות |
| **נובמבר 2028** | MT940/MT942/MT950/MT900/MT910 יצא לפנסיה מלאה | פורמטים של הצהרה מדור קודם אינם זמינים עוד; CAMT.052/.053/.054 הם האפשרות היחידה |

## מה משתנה עבור הקוד שלך

### לפני: MT940 בלבד

```python
from bankstatementparser import Mt940Parser

parser = Mt940Parser("statement.mt940")
df = parser.parse()
```

### אחרי: שני הפורמטים עם זיהוי אוטומטי

```python
from bankstatementparser import create_parser, detect_statement_format

fmt = detect_statement_format("statement.xml")  # or .mt940
parser = create_parser("statement.xml", fmt)
df = parser.parse()  # Same DataFrame schema regardless of format
```

ה`detect_statement_format()`הפונקציה מזהה אם הקובץ הוא MT940, CAMT.053, PAIN.001, או כל פורמט נתמך אחר. ה`create_parser()`הפונקציה מחזירה את המנתח הנכון. הקוד במורד הזרם שלך פועל באופן זהה ללא קשר לפורמט המקור.

## CAMT.053 לעומת MT940: הבדלים עיקריים

| תכונה | MT940 | CAMT.053 |
|---|---|---|
| עושר נתונים | שדות מוגבלים | פי 3-5 יותר נתונים לכל עסקה |
| סט תווים | מוגבל (ערכת תווים SWIFT) | יוניקוד מלא |
| מִבְנֶה | טקסט שטוח עם תגים | XML עם מרחבי שמות |
| דיווח איזון | פתיחה/סגירה בלבד | סוגי איזון מרובים |
| הפניות | שדה התייחסות יחיד | סוגי התייחסות מרובים |
| טיפול במטבעות | בְּסִיסִי | ריבוי מטבעות מלא עם שערי חליפין |

## כיצד מנתח דפי חשבון בנק עוזר

- **ממשק API מאוחד**: נתח גם את MT940 וגם את CAMT.053 עם אותו הדבר`parse()`שיטה, הפקת סכימות DataFrame זהות.
- **זיהוי אוטומטי**: אין צורך לדעת את הפורמט מראש.`detect_statement_format()`מזהה אותו אוטומטית.
- **Namespace-agnostic**: מטפל בכל גרסת CAMT.053 (001.02, 001.04 או עטיפות ספציפיות לבנק) ללא תצורה.
- **סטרימינג**: עבד קבצי CAMT גדולים (50 MB+, 50K+ טרנזקציות) עם זיכרון מוגבל.
- **בדיקת הגירה**: הפעל את שני המנתחים זה לצד זה באותו טווח תאריכים כדי לאמת את עקביות הפלט לפני המעבר.
