Wir freuen uns über Beiträge von Entwicklern, technischen Redakteuren und allen, die daran interessiert sind, die Analyse von Kontoauszügen für die Finanzwelt zu verbessern.

## So leisten Sie einen Beitrag

### Probleme melden

Haben Sie einen Fehler gefunden oder haben Sie eine Funktionsanfrage? [Öffnen Sie ein Problem auf GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). Bitte beifügen:

- Eine klare Beschreibung des Problems oder Vorschlags.
- Schritte zur Reproduktion (bei Fehlern).
- Ihre Python-Version und Ihr Betriebssystem.

### Code senden

1. Forken Sie das [Repository](https://github.com/sebastienrousseau/bankstatementparser).
2. Erstellen Sie einen Feature-Zweig (`git checkout -b feature/your-feature`).
3. Schreiben Sie Tests für Ihre Änderungen (wir benötigen eine Filialabdeckung von 100 %).
4. Führen Sie die Testsuite aus:`pytest`.
5. Senden Sie eine Pull-Anfrage mit einer klaren Beschreibung.

### Dokumentation verbessern

Verbesserungen der Dokumentation sind jederzeit willkommen. Du kannst:

- Korrigieren Sie Tippfehler oder klären Sie vorhandene Inhalte.
- Fügen Sie dem [Beispielverzeichnis] ​​neue Anwendungsbeispiele hinzu(https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- Dokumentzeichenfolgen im Quellcode verbessern.

## Entwicklungs-Setup

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## Code-Standards

- Der gesamte Code muss bestehen`ruff`Flusen und`mypy`Typprüfung.
- Alle Commits müssen signiert sein.
– Alle Pull-Anfragen müssen eine Zweigabdeckung von 100 % gewährleisten.
- Befolgen Sie den vorhandenen Codestil und die vorhandenen Muster.
