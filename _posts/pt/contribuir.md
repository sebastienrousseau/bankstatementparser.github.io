Agradecemos contribuições de desenvolvedores, redatores técnicos e qualquer pessoa interessada em melhorar a análise de extratos bancários para a comunidade financeira.

## Como contribuir

### Relatar problemas

Encontrou um bug ou tem uma solicitação de recurso? [Abra um problema no GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). Por favor inclua:

- Uma descrição clara do problema ou sugestão.
- Passos para reproduzir (para bugs).
- Sua versão Python e sistema operacional.

### Enviar código

1. Bifurque o [repositório](https://github.com/sebastienrousseau/bankstatementparser).
2. Crie uma ramificação de recurso (`git checkout -b feature/your-feature`).
3. Escreva testes para suas alterações (exigimos 100% de cobertura de filiais).
4. Execute o conjunto de testes:`pytest`.
5. Envie uma solicitação pull com uma descrição clara.

### Melhorar a documentação

Melhorias na documentação são sempre bem-vindas. Você pode:

- Corrija erros de digitação ou esclareça o conteúdo existente.
- Adicione novos exemplos de uso ao [diretório de exemplos](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- Melhorar docstrings no código fonte.

## Configuração de desenvolvimento

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## Padrões de código

- Todo código deve passar`ruff`linting e`mypy`verificação de tipo.
- Todos os commits devem ser assinados.
- Todas as solicitações pull devem manter 100% de cobertura das filiais.
- Siga o estilo e os padrões de código existentes.

## Patrocine o Projeto

Se o Bank Statement Parser economizar o tempo da sua equipe, considere [patrocinar o projeto no GitHub](https://github.com/sponsors/sebastienrousseau). Seu apoio nos ajuda a manter e melhorar a biblioteca.
