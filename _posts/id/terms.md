## Persetujuan terhadap Persyaratan

Dengan mengakses bankstatementparser.com ("Situs Web") dan menggunakan perpustakaan Parser Laporan Bank ("Perangkat Lunak"), Anda setuju untuk terikat oleh Ketentuan Penggunaan ini. Jika Anda tidak setuju, mohon jangan gunakan Situs Web atau Perangkat Lunak.

## Lisensi Sumber Terbuka

Pustaka Parser Laporan Bank dirilis di bawah [Lisensi Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0). Anda dapat menggunakan, memodifikasi, dan mendistribusikan Perangkat Lunak sesuai dengan lisensi tersebut. Teks lisensi lengkap tersedia di [repositori GitHub](https://github.com/sebastienrousseau/bankstatementparser/blob/main/LICENSE).

## Penggunaan Situs Web

Anda dapat menggunakan Situs Web hanya untuk tujuan yang sah. Anda setuju untuk tidak:

- Mencoba mendapatkan akses tidak sah ke bagian mana pun dari Situs Web.
- Menggunakan Situs Web untuk mengirimkan kode berbahaya atau melakukan serangan penolakan layanan.
- Mereproduksi, menggandakan, atau menjual kembali bagian mana pun dari Situs Web tanpa izin tertulis.

## Penggunaan Perangkat Lunak

Perangkat Lunak ini disediakan untuk menguraikan file laporan bank secara lokal di sistem Anda sendiri. Anda sepenuhnya bertanggung jawab untuk:

- Memastikan penggunaan Anda atas Perangkat Lunak mematuhi hukum dan peraturan yang berlaku.
- Keakuratan dan integritas data yang diproses oleh Perangkat Lunak.
- Mengamankan data keuangan sensitif apa pun yang diproses menggunakan Perangkat Lunak.

## Kekayaan Intelektual

Nama, logo, dan konten situs web Parser Laporan Bank adalah milik Sebastien Rousseau. Kode sumber Perangkat Lunak dilisensikan di bawah Apache 2.0 seperti dijelaskan di atas.
