เรายินดีรับการสนับสนุนจากนักพัฒนา นักเขียนด้านเทคนิค และทุกคนที่สนใจในการปรับปรุงการแยกวิเคราะห์ใบแจ้งยอดธนาคารสำหรับชุมชนการเงิน

## วิธีการมีส่วนร่วม

### รายงานปัญหา

พบข้อบกพร่องหรือมีการร้องขอคุณสมบัติ? [เปิดปัญหาบน GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). กรุณาระบุ:

- คำอธิบายปัญหาหรือข้อเสนอแนะที่ชัดเจน
- ขั้นตอนในการสืบพันธุ์ (สำหรับข้อบกพร่อง)
- เวอร์ชัน Python และระบบปฏิบัติการของคุณ

### ส่งรหัส

1. แยก [repository](https://github.com/sebastienrousseau/bankstatementparser).
2. สร้างสาขาคุณลักษณะ (`git checkout -b feature/your-feature`).
3. เขียนการทดสอบการเปลี่ยนแปลงของคุณ (เราต้องการการครอบคลุมสาขา 100%)
4. เรียกใช้ชุดทดสอบ:`pytest`.
5. ส่งคำขอดึงพร้อมคำอธิบายที่ชัดเจน

### ปรับปรุงเอกสาร

เรายินดีรับการปรับปรุงเอกสารประกอบเสมอ คุณสามารถ:

- แก้ไขคำผิดหรือชี้แจงเนื้อหาที่มีอยู่
- เพิ่มตัวอย่างการใช้งานใหม่ให้กับ [ไดเร็กทอรีตัวอย่าง](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- ปรับปรุงเอกสารในซอร์สโค้ด

## การตั้งค่าการพัฒนา

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## มาตรฐานรหัส

- รหัสทั้งหมดจะต้องผ่าน`ruff`ผ้าสำลีและ`mypy`การตรวจสอบประเภท
- ข้อตกลงทั้งหมดจะต้องลงนาม
- คำขอดึงทั้งหมดจะต้องรักษาความครอบคลุมของสาขา 100%
- ปฏิบัติตามรูปแบบและรูปแบบของโค้ดที่มีอยู่
