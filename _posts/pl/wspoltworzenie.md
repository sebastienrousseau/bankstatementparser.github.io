## Jak wnieść swój wkład

### Zgłoś problemy

Znalazłeś błąd lub masz prośbę o nową funkcję? [Otwórz problem w GitHubie](https://github.com/sebastienrousseau/bankstatementparser/issues). Proszę uwzględnić:

- Jasny opis problemu lub sugestii.
- Kroki do odtworzenia (w przypadku błędów).
- Twoja wersja Pythona i system operacyjny.

### Prześlij kod

1. Rozwidl [repozytorium](https://github.com/sebastienrousseau/bankstatementparser).
2. Utwórz gałąź funkcji (`git checkout -b feature/your-feature`).
3. Napisz testy dla swoich zmian (wymagamy 100% pokrycia oddziałów).
4. Uruchom zestaw testów:`pytest`.
5. Prześlij żądanie ściągnięcia z jasnym opisem.

### Ulepsz dokumentację

Ulepszenia dokumentacji są zawsze mile widziane. Możesz:

- Popraw literówki lub wyjaśnij istniejącą treść.
- Dodaj nowe przykłady użycia do [katalogu przykładów](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- Popraw dokumenty w kodzie źródłowym.

## Konfiguracja programistyczna

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## Standardy kodu

- Cały kod musi przejść`ruff`kłaczenie i`mypy`sprawdzanie typu.
- Wszystkie zatwierdzenia muszą być podpisane.
- Wszystkie żądania ściągnięcia muszą zapewniać 100% pokrycie oddziałów.
- Postępuj zgodnie z istniejącym stylem i wzorcami kodu.
