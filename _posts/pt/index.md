**Bank Statement Parser** é uma biblioteca Python de código aberto que analisa extratos bancários de seis formatos (CAMT.053, PAIN.001, CSV, OFX, QFX, MT940) em DataFrames pandas estruturados. Todo o processamento é executado localmente: zero chamadas de rede, saída determinística e redação automática de PII.

## Comece em segundos

```bash
pip install bankstatementparser
```

```python
from bankstatementparser import create_parser, detect_statement_format

fmt = detect_statement_format("statement.xml")
parser = create_parser("statement.xml", fmt)
df = parser.parse()  # pandas DataFrame, ready to use
```

## Uma biblioteca, seis formatos

Analise CAMT.053, PAIN.001, CSV, OFX, QFX e MT940 em DataFrames pandas estruturados com uma API única e unificada. Não há necessidade de instalar pacotes separados para cada formato.

| Recurso | Analisador de extrato bancário | OSS de formato único (mt940, ofxparse) | SaaS (Ocrolus, Parseur) |
|---|---|---|---|
| Formatos suportados | 6, API unificada | 1 cada | Muitos (via OCR) |
| Privacidade de dados | 100% local, zero chamadas de rede | 100% locais | Dados enviados externamente |
| Custo | Gratuito, Apache 2.0 | Livre | $ 49- $ 1.000 +/mês |
| Redação de PII | Integrado, ativado por padrão | Não | Varia |
| Transmissão | Memória limitada | Não | N / D |
| Segurança ZIP | Endurecimento integrado | Não | N / D |
| Desduplicação | Integrado com pontuações de confiança | Não | Alguns |

## Construído para a migração ISO 20022

A SWIFT estabeleceu prazos firmes: todas as instituições financeiras devem receber o CAMT.053 até novembro de 2027, e o MT940/MT942/MT950 será totalmente desativado até novembro de 2028. O Bank Statement Parser lida com o MT940 legado e os formatos modernos ISO 20022 (CAMT.053, PAIN.001) em uma única API, para que seu pipeline de análise funcione durante a transição e além.

## Desempenho

- **27.000+ transações/segundo** para análise CAMT.053
- **52.000+ transações/segundo** para análise PAIN.001
- **< 2 ms** tempo para o primeiro resultado
- **Memória constante** de 1 mil a mais de 50 mil transações via streaming
- **467 testes** com 100% de cobertura de ramificação em Python 3.9 a 3.14

## Por que analisador de extrato bancário?

- **Detecção automática de formato**:`detect_statement_format()`identifica arquivos automaticamente e`create_parser()`retorna o analisador correto.
- **Privacidade em primeiro lugar**: a redação de PII está ativada por padrão. Campos confidenciais (nomes, IBANs, endereços) são mascarados na saída CLI. Ative com`--show-pii`quando necessário.
- **Pronto para produção**: ingestão segura de ZIP (proteção contra bombas, rejeição de entrada criptografada), validação de entrada e prevenção de passagem de caminho.
- **Saída flexível**: exporte para CSV, JSON, Excel ou converta para Polars DataFrames.
- **Processamento paralelo**: analisa vários arquivos simultaneamente com`parse_files_parallel()`.


## Construído para produção

O Bank Statement Parser foi projetado para equipes de tesouraria, desenvolvedores de fintech e responsáveis ​​pela conformidade que processam dados financeiros confidenciais. A biblioteca é usada em pipelines de migração MT940 para CAMT, sistemas de reconciliação automatizados e fluxos de trabalho de auditoria regulatória em instituições financeiras.

- **467 testes** com 100% de cobertura de ramificação em Python 3.9 a 3.14
