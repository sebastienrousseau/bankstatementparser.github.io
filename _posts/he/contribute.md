## כיצד לתרום

### דווח על בעיות

מצאתם באג או יש לכם בקשת תכונה? [פתח בעיה ב-GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). נא לכלול:

- תיאור ברור של הבעיה או ההצעה.
- שלבים לשכפול (עבור באגים).
- גרסת Python ומערכת ההפעלה שלך.

### שלח קוד

1. מזלג את [המחסן](https://github.com/sebastienrousseau/bankstatementparser).
2. צור ענף תכונה (`git checkout -b feature/your-feature`).
3. כתבו מבחנים לשינויים שלכם (אנו דורשים כיסוי של 100% סניף).
4. הפעל את חבילת הבדיקה:`pytest`.
5. שלח בקשת משיכה עם תיאור ברור.

### שפר את התיעוד

שיפורי תיעוד יתקבלו תמיד בברכה. אתה יכול:

- תקן שגיאות הקלדה או הבהרת תוכן קיים.
- הוסף דוגמאות שימוש חדשות ל[ספריית הדוגמאות](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- שפר מחרוזות docstrings בקוד המקור.

## הגדרת פיתוח

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## תקני קוד

- כל הקוד חייב לעבור`ruff`מוך ו`mypy`בדיקת סוג.
- יש לחתום על כל ההתחייבויות.
- כל בקשות המשיכה חייבות לשמור על כיסוי סניף של 100%.
- עקוב אחר סגנון הקוד והדפוסים הקיימים.
