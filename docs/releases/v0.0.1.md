## Highlights ⭐️

* **The first public site**: We published bankstatementparser.com, the documentation site for the Bank Statement Parser library, built with the Static Site Generator (ssg) and served by GitHub Pages.
* **Start here**: The site introduces the project, shows how to install the CLI and library, explores supported bank dialects (PDF, CSV, OFX, MT940, CAMT.053), and links to its source and licence.
