Nous apprécions les contributions des développeurs, des rédacteurs techniques et de toute personne intéressée par l’amélioration de l’analyse des relevés bancaires pour la communauté financière.

## Comment contribuer

### Signaler des problèmes

Vous avez trouvé un bug ou avez une demande de fonctionnalité ? [Ouvrir un ticket sur GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). Veuillez inclure :

- Une description claire du problème ou de la suggestion.
- Étapes à reproduire (pour les bugs).
- Votre version Python et votre système d'exploitation.

### Soumettre le code

1. Forkez le [dépôt](https://github.com/sebastienrousseau/bankstatementparser).
2. Créez une branche de fonctionnalités (`git checkout -b feature/your-feature`).
3. Écrivez des tests pour vos modifications (nous exigeons une couverture de succursales à 100 %).
4. Exécutez la suite de tests :`pytest`.
5. Soumettez une pull request avec une description claire.

### Améliorer la documentation

Les améliorations de la documentation sont toujours les bienvenues. Tu peux:

- Corrigez les fautes de frappe ou clarifiez le contenu existant.
- Ajouter de nouveaux exemples d'utilisation au [répertoire d'exemples](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- Améliorer les docstrings dans le code source.

## Configuration du développement

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## Normes des codes

- Tout le code doit réussir`ruff`le peluchage et`mypy`vérification de type.
- Tous les commits doivent être signés.
- Toutes les demandes de tirage doivent maintenir une couverture de succursales à 100 %.
- Suivez le style et les modèles de code existants.

## Parrainez le projet

Si Bank Statement Parser fait gagner du temps à votre équipe, envisagez de [sponsoriser le projet sur GitHub](https://github.com/sponsors/sebastienrousseau). Votre soutien nous aide à maintenir et à améliorer la bibliothèque.
