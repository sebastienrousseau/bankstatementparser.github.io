We verwelkomen bijdragen van ontwikkelaars, technische schrijvers en iedereen die geïnteresseerd is in het verbeteren van het parseren van bankafschriften voor de financiële gemeenschap.

## Hoe u kunt bijdragen

### Rapporteer problemen

Heeft u een bug gevonden of heeft u een functieverzoek? [Open een probleem op GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). Vermeld alstublieft:

- Een duidelijke omschrijving van het probleem of de suggestie.
- Stappen om te reproduceren (voor bugs).
- Uw Python-versie en besturingssysteem.

### Verstuur code

1. Fork de [repository](https://github.com/sebastienrousseau/bankstatementparser).
2. Maak een feature branch (`git checkout -b feature/your-feature`).
3. Schrijf tests voor uw wijzigingen (we vereisen 100% vestigingsdekking).
4. Voer het testpakket uit:`pytest`.
5. Dien een pull request in met een duidelijke omschrijving.

### Documentatie verbeteren

Verbeteringen in de documentatie zijn altijd welkom. U kunt:

- Corrigeer typefouten of verduidelijk bestaande inhoud.
- Voeg nieuwe gebruiksvoorbeelden toe aan de map [voorbeelden](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- Verbeter docstrings in de broncode.

## Ontwikkelingsopstelling

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## Codestandaarden

- Alle code moet passeren`ruff`linten en`mypy`typecontrole.
- Alle commits moeten worden ondertekend.
- Alle pull-aanvragen moeten een vestigingsdekking van 100% behouden.
- Volg de bestaande codestijl en patronen.
