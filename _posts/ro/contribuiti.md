Salutăm contribuțiile dezvoltatorilor, scriitorilor tehnici și oricui este interesat de îmbunătățirea analizei extraselor bancare pentru comunitatea financiară.

## Cum să contribui

### Raportați probleme

Ați găsit o eroare sau aveți o solicitare de funcție? [Deschideți o problemă pe GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). Vă rugăm să includeți:

- O descriere clară a problemei sau a sugestiei.
- Pași de reproducere (pentru bug-uri).
- Versiunea dvs. Python și sistemul de operare.

### Trimiteți codul

1. Bifurcați [repozitivul](https://github.com/sebastienrousseau/bankstatementparser).
2. Creați o ramură caracteristică (`git checkout -b feature/your-feature`).
3. Scrieți teste pentru modificările dvs. (necesităm acoperire 100% sucursală).
4. Rulați suita de teste:`pytest`.
5. Trimiteți o cerere de extragere cu o descriere clară.

### Îmbunătățiți documentația

Îmbunătățirile documentației sunt întotdeauna binevenite. Puteți:

- Remediați greșelile de scriere sau clarificați conținutul existent.
- Adăugați noi exemple de utilizare în [directorul exemple](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- Îmbunătățiți documentele din codul sursă.

## Configurare dezvoltare

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## Standarde de cod

- Tot codul trebuie să treacă`ruff`scame și`mypy`verificarea tipului.
- Toate angajamentele trebuie semnate.
- Toate cererile de retragere trebuie să mențină o acoperire de 100% sucursale.
- Urmați stilul și modelele de cod existente.
