## Yadda ake Gudunmawa

### Batun Rahoto

An sami bug ko kuna da buƙatun fasali? [Bude batu akan GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). Da fatan za a haɗa:

- Bayyanar matsala ko shawara.
- Matakan haifuwa (don kwari).
- Sigar Python ku da tsarin aiki.

### Gabatar da Code

1. Kashe [majiya](https://github.com/sebastienrousseau/bankstatementparser).
2. Ƙirƙiri reshen fasali (`git checkout -b feature/your-feature`).
3. Rubuta gwaje-gwaje don canje-canjenku (muna buƙatar 100% ɗaukar hoto).
4. Guda dakin gwaji:`pytest`.
5. Gabatar da buƙatun ja tare da bayyananniyar kwatanci.

### Inganta Takardu

Ana maraba da haɓaka daftarin aiki koyaushe. Za ka iya:

- Gyara typos ko bayyana abubuwan da ke akwai.
- Ƙara sabon misalan amfani zuwa [misali directory](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- Inganta takardun shaida a cikin lambar tushe.

## Saitin Ci gaba

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```
