# Contributing to Bank Statement Parser

Thank you for your interest in contributing to Bank Statement Parser. We welcome pull requests for new bank dialect parsers, performance optimizations, and documentation improvements.

## Development Workflow

1. Fork the repository on GitHub: `https://github.com/sebastienrousseau/bankstatementparser`
2. Clone your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/bankstatementparser.git
   cd bankstatementparser
   ```
3. Run the test suite:
   ```bash
   cargo test
   ```
4. Submit your pull request with descriptive commit messages and test fixtures with anonymized PII.
