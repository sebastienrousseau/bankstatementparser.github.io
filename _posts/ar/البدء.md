## متطلبات

- بايثون 3.9 إلى 3.14
- الوصول إلى المحطة الطرفية (macOS أو Linux أو WSL)

## ثَبَّتَ

```bash
pip install bankstatementparser
```

لدعم Polars DataFrame:

```bash
pip install bankstatementparser[polars]
```

## بداية سريعة

### الكشف التلقائي وتحليل أي تنسيق

```python
from bankstatementparser import create_parser, detect_statement_format

fmt = detect_statement_format("transactions.ofx")
parser = create_parser("transactions.ofx", fmt)
df = parser.parse()  # pandas DataFrame
print(df.head())
```

هذا يعمل مع`.xml`(كامت/PAIN.001)،`.csv`, `.ofx`, `.qfx`, `.mt940`، و`.sta`ملفات.

### تحليل CAMT.053

```python
from bankstatementparser import CamtParser

parser = CamtParser("statement.xml")
transactions = parser.parse()
```

### تحليل PAIN.001

```python
from bankstatementparser import Pain001Parser

parser = Pain001Parser("payment.xml")
payments = parser.parse()
```

## تدفق الملفات الكبيرة

بالنسبة للملفات التي تحتوي على آلاف المعاملات، استخدم الدفق للحفاظ على الذاكرة محدودة:

```python
parser = CamtParser("large_statement.xml")
for transaction in parser.parse_streaming(redact_pii=True):
    process(transaction)  # Memory stays constant
```

## التحليل داخل الذاكرة

التحليل من وحدات البايت بدون إدخال/إخراج القرص - مفيد لسير عمل SFTP أو API:

```python
xml_bytes = download_from_sftp()
parser = CamtParser.from_bytes(xml_bytes, source_name="daily.xml")
transactions = parser.parse()
```

## معالجة الملفات الموازية

تحليل ملفات متعددة في وقت واحد:

```python
from bankstatementparser import parse_files_parallel

results = parse_files_parallel([
    "statements/jan.xml",
    "statements/feb.xml",
    "statements/mar.xml",
])
for r in results:
    print(r.path, r.status, len(r.transactions), "rows")
```

## إلغاء البيانات المكررة

اكتشف التكرارات الدقيقة والمطابقات المشتبه بها باستخدام درجات الثقة:

```python
from bankstatementparser import CamtParser, Deduplicator

parser = CamtParser("statement.xml")
dedup = Deduplicator()
result = dedup.deduplicate(dedup.from_dataframe(parser.parse()))

print(f"Unique: {len(result.unique_transactions)}")
print(f"Exact duplicates: {len(result.exact_duplicates)}")
print(f"Suspected matches: {len(result.suspected_matches)}")
```

## معالجة الرمز البريدي الآمن

معالجة ملفات XML المضغوطة باستخدام فحوصات الأمان المضمنة (الحماية من القنابل، ورفض الإدخال المشفر):

```python
from bankstatementparser import iter_secure_xml_entries, CamtParser

for entry in iter_secure_xml_entries("statements.zip"):
    parser = CamtParser.from_bytes(entry.xml_bytes, source_name=entry.source_name)
    print(f"{entry.source_name}: {len(parser.parse())} transactions")
```

## يصدّر

```python
parser = CamtParser("statement.xml")
parser.export_csv("output.csv")
parser.export_json("output.json")

# Polars (requires bankstatementparser[polars])
polars_df = parser.to_polars()
```

## استخدام سطر الأوامر

```bash
# Parse and display
python -m bankstatementparser.cli --type camt --input statement.xml

# Export to CSV
python -m bankstatementparser.cli --type camt --input statement.xml --output transactions.csv

# Stream with PII visible
python -m bankstatementparser.cli --type camt --input statement.xml --streaming --show-pii
```

خيارات سطر الأوامر:

- `--type {camt,pain001}`- نوع المحلل
-`--input <path>`- ملف الإدخال
-`--output <csv_path>`- التصدير إلى CSV
-`--streaming`- دفق الملفات الكبيرة
-`--show-pii`- إظهار الحقول الحساسة (تم تنقيحها افتراضيًا)
-`--max-size <MB>`- الحد الأقصى لحجم الملف

## مرجع واجهة برمجة التطبيقات

### فئات المحلل اللغوي

| فصل | شكل | يستورد |
|---|---|---|
| `CamtParser` | CAMT.053 (آيزو 20022) | `from bankstatementparser import CamtParser` |
| `Pain001Parser` | PAIN.001 (آيزو 20022) | `from bankstatementparser import Pain001Parser` |
| `CsvStatementParser` | CSV | `from bankstatementparser import CsvStatementParser` |
| `OfxParser` | أوفس | `from bankstatementparser import OfxParser` |
| `QfxParser` | كيو اف اكس | `from bankstatementparser import QfxParser` |
| `Mt940Parser` | MT940 | `from bankstatementparser import Mt940Parser` |

### وظائف المرافق

| وظيفة | غاية |
|---|---|
| `detect_statement_format(path)` | الكشف التلقائي عن تنسيق الملف |
| `create_parser(path, fmt)` | إنشاء المحلل اللغوي المناسب |
| `parse_files_parallel(paths)` | تحليل ملفات متعددة في وقت واحد |
| `iter_secure_xml_entries(zip_path)` | تكرار إدخالات ZIP بشكل آمن |

### فئات البيانات

| فصل | غاية |
|---|---|
| `Deduplicator` | كشف المعاملات المكررة |
| `DeduplicationResult` | النتيجة بمطابقات فريدة ودقيقة ومشتبه بها |
| `InputValidator` | التحقق من صحة مسارات الملفات وتنسيقاتها |
| `Transaction` | سجل المعاملات الطبيعي |
| `FileResult` | النتيجة من التحليل الموازي |
| `ZipXMLSource` | غلاف عضو ZIP |

### الاستثناءات

| استثناء | عندما رفعت |
|---|---|
| `ParserError` | تحليل الفشل |
| `ExportError` | فشل التصدير (CSV/JSON/Excel) |
| `ValidationError` | فشل التحقق من صحة الإدخال |
| `ZipSecurityError` | فشل فحص أمان ZIP |
