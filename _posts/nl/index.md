**Bank Statement Parser** is een open-source Python-bibliotheek die bankafschriften uit zes formaten (CAMT.053, PAIN.001, CSV, OFX, QFX, MT940) parseert in gestructureerde panda's DataFrames. Alle verwerking vindt lokaal plaats: geen netwerkoproepen, deterministische uitvoer en automatische PII-redactie.

## Ga binnen enkele seconden aan de slag

```bash
pip install bankstatementparser
```

```python
from bankstatementparser import create_parser, detect_statement_format

fmt = detect_statement_format("statement.xml")
parser = create_parser("statement.xml", fmt)
df = parser.parse()  # pandas DataFrame, ready to use
```

## Eén bibliotheek, zes formaten

Parseer CAMT.053, PAIN.001, CSV, OFX, QFX en MT940 in gestructureerde panda's DataFrames met één enkele, uniforme API. Het is niet nodig om voor elk formaat afzonderlijke pakketten te installeren.

| Functie | Parser voor bankafschriften | OSS met één formaat (mt940, ofxparse) | SaaS (Ocrolus, Parseur) |
|---|---|---|---|
| Ondersteunde formaten | 6, uniforme API | 1 elk | Veel (via OCR) |
| Gegevensprivacy | 100% lokaal, geen netwerkoproepen | 100% lokaal | Gegevens extern verzonden |
| Kosten | Gratis, Apache 2.0 | Vrij | $ 49-$ 1.000+/maand |
| PII-redactie | Ingebouwd, standaard ingeschakeld | Nee | Varieert |
| Streamen | Beperkt geheugen | Nee | N.v.t |
| ZIP-beveiliging | Ingebouwde verharding | Nee | N.v.t |
| Ontdubbeling | Ingebouwd met betrouwbaarheidsscores | Nee | Sommige |

## Gebouwd voor de ISO 20022-migratie

SWIFT heeft vaste deadlines gesteld: alle financiële instellingen moeten CAMT.053 ontvangen tegen november 2027, en MT940/MT942/MT950 zal in november 2028 volledig buiten gebruik worden gesteld. Bankafschriftparser verwerkt zowel de oudere MT940- als de moderne ISO 20022-formaten (CAMT.053, PAIN.001) in één enkele API, zodat uw parseerpijplijn tijdens de transitie en daarna blijft werken.

## Prestatie

- **27.000+ transacties/seconde** voor CAMT.053-parsering
- **52.000+ transacties/seconde** voor PAIN.001-parsing
- **< 2 ms** tijd tot eerste resultaat
- **Constant geheugen** van 1K tot 50K+ transacties via streaming
- **467 tests** met 100% vertakkingsdekking in Python 3.9 tot 3.14

## Waarom bankafschriftparser?

- **Formaat automatische detectie**:`detect_statement_format()`identificeert bestanden automatisch en`create_parser()`retourneert de juiste parser.
- **Privacy First**: PII-redactie is standaard ingeschakeld. Gevoelige velden (namen, IBAN's, adressen) worden gemaskeerd in de CLI-uitvoer. Meld u aan met`--show-pii`wanneer nodig.
- **Gereed voor productie**: Veilige ZIP-opname (bombescherming, versleutelde afwijzing van toegang), invoervalidatie en preventie van pad-traversal.
- **Flexibele uitvoer**: exporteer naar CSV, JSON, Excel of converteer naar Polars DataFrames.
- **Parallelle verwerking**: parseer meerdere bestanden gelijktijdig met`parse_files_parallel()`.
