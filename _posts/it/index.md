**Bank Statement Parser** è una libreria Python open source che analizza estratti conto da sei formati (CAMT.053, PAIN.001, CSV, OFX, QFX, MT940) in DataFrames panda strutturati. Tutta l'elaborazione viene eseguita localmente: zero chiamate di rete, output deterministico e redazione automatica delle PII.

## Inizia in pochi secondi

```bash
pip install bankstatementparser
```

```python
from bankstatementparser import create_parser, detect_statement_format

fmt = detect_statement_format("statement.xml")
parser = create_parser("statement.xml", fmt)
df = parser.parse()  # pandas DataFrame, ready to use
```

## Una libreria, sei formati

Analizza CAMT.053, PAIN.001, CSV, OFX, QFX e MT940 in DataFrames panda strutturati con un'unica API unificata. Non è necessario installare pacchetti separati per ciascun formato.

| Caratteristica | Analizzatore di estratti conto bancari | OSS a formato singolo (mt940, ofxparse) | SaaS (Ocrolus, Parseur) |
|---|---|---|---|
| Formati supportati | 6, API unificata | 1 ciascuno | Molti (tramite OCR) |
| Privacy dei dati | 100% locale, zero chiamate di rete | 100% locale | Dati inviati all'esterno |
| Costo | Gratuito, Apache 2.0 | Gratuito | $49-$1.000+/mese |
| Redazione PII | Integrato, attivo per impostazione predefinita | NO | Varia |
| Streaming | Memoria limitata | NO | N / A |
| Sicurezza ZIP | Indurimento incorporato | NO | N / A |
| Deduplicazione | Integrato con punteggi di confidenza | NO | Alcuni |

## Costruito per la migrazione ISO 20022

SWIFT ha fissato scadenze precise: tutti gli istituti finanziari devono ricevere CAMT.053 entro novembre 2027 e MT940/MT942/MT950 saranno completamente ritirati entro novembre 2028. Bank Statement Parser gestisce sia i formati MT940 legacy che i moderni formati ISO 20022 (CAMT.053, PAIN.001) in un'unica API, quindi la pipeline di analisi funziona durante la transizione e oltre.

## Prestazione

- **27.000+ transazioni/secondo** per l'analisi CAMT.053
- **52.000+ transazioni/secondo** per l'analisi PAIN.001
- **< 2 ms** tempo per il primo risultato
- **Memoria costante** da 1.000 a oltre 50.000 transazioni tramite streaming
- **467 test** con copertura delle filiali del 100% su Python da 3.9 a 3.14

## Perché il parser di estratto conto?

- **Rilevamento automatico formato**:`detect_statement_format()`identifica i file automaticamente e`create_parser()`restituisce il parser corretto.
- **Privacy First**: la redazione delle PII è attiva per impostazione predefinita. I campi sensibili (nomi, IBAN, indirizzi) sono mascherati nell'output CLI. Partecipa con`--show-pii`quando necessario.
- **Produzione pronta**: inserimento sicuro di ZIP (protezione anti-bomb, rifiuto di voci crittografate), convalida dell'input e prevenzione dell'attraversamento del percorso.
- **Output flessibile**: esporta in CSV, JSON, Excel o converti in Polars DataFrames.
- **Elaborazione parallela**: analizza più file contemporaneamente con`parse_files_parallel()`.

La libreria viene utilizzata nelle pipeline di migrazione da MT940 a CAMT, nei sistemi di riconciliazione automatizzata e nei flussi di lavoro di audit normativo tra gli istituti finanziari.
