Agradecemos las contribuciones de desarrolladores, redactores técnicos y cualquier persona interesada en mejorar el análisis de extractos bancarios para la comunidad financiera.

## Cómo contribuir

### Informar problemas

¿Encontró un error o tiene una solicitud de función? [Abrir un problema en GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). Por favor incluya:

- Una descripción clara del problema o sugerencia.
- Pasos para reproducir (para errores).
- Su versión de Python y sistema operativo.

### Enviar código

1. Bifurque el [repositorio](https://github.com/sebastienrousseau/bankstatementparser).
2. Cree una rama de funciones (`git checkout -b feature/your-feature`).
3. Escriba pruebas para sus cambios (requerimos una cobertura de sucursal del 100%).
4. Ejecute el conjunto de pruebas:`pytest`.
5. Envíe una solicitud de extracción con una descripción clara.

### Mejorar la documentación

Las mejoras en la documentación siempre son bienvenidas. Puede:

- Corregir errores tipográficos o aclarar contenido existente.
- Agregar nuevos ejemplos de uso al [directorio de ejemplos](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- Mejorar las cadenas de documentación en el código fuente.

## Configuración de desarrollo

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## Estándares de código

- Todo el código debe pasar`ruff`pelusa y`mypy`verificación de tipos.
- Todos los compromisos deben estar firmados.
- Todas las solicitudes de extracción deben mantener una cobertura de sucursales del 100 %.
- Siga el estilo y los patrones del código existente.

## Patrocinar el proyecto

Si Bank Statement Parser le ahorra tiempo a su equipo, considere [patrocinar el proyecto en GitHub](https://github.com/sponsors/sebastienrousseau). Su apoyo nos ayuda a mantener y mejorar la biblioteca.
