# Contributing

Thank you for contributing to the Bank Statement Parser documentation website.

1. Open an issue for substantial changes.
2. Branch from `main` using `feat/vX.Y.Z`.
3. Follow `DEVELOPMENT.md`, run `make verify`, and update `CHANGELOG.md`.
4. Commit with SSH signature and DCO trailer: `git commit -S -s`.
5. Open a pull request. Do not merge until all CI checks are green.
