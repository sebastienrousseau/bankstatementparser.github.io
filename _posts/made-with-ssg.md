# Made with Static Site Generator (SSG)

This site is natively compiled using the high-performance **Static Site Generator (SSG)** written in Rust.

- **Source of Truth:** Content authored in Markdown (`_posts/*.md`) with Tera templates (`_layouts/*.html`).
- **Compilation Speed:** Full site generation in under 0.5 seconds with zero runtime JavaScript framework dependencies.
- **Security:** Strict Subresource Integrity (SRI) and Content Security Policy (CSP) headers.
