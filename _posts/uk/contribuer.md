## Як зробити внесок

### Повідомити про проблеми

Знайшли помилку або маєте запит на доповнення? [Відкрити випуск на GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). Будь ласка, додайте:

- Чіткий опис проблеми або пропозиції.
- Кроки для відтворення (для помилок).
- Ваша версія Python і операційна система.

### Надіслати код

1. Розгалужте [репозиторій](https://github.com/sebastienrousseau/bankstatementparser).
2. Створіть гілку функції (`git checkout -b feature/your-feature`).
3. Напишіть тести для ваших змін (ми вимагаємо 100% покриття гілок).
4. Запустіть набір тестів:`pytest`.
5. Надішліть запит на отримання з чітким описом.

### Покращити документацію

Покращення документації завжди вітаються. Ви можете:

- Виправте помилки або уточніть наявний вміст.
- Додайте нові приклади використання до [каталогу прикладів](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
— Покращено рядки документів у вихідному коді.

## Налаштування розробки

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## Стандарти коду

- Весь код має пройти`ruff`розпушування і`mypy`перевірка типу.
- Усі коміти мають бути підписані.
- Усі запити на вилучення мають підтримувати 100% покриття гілок.
- Дотримуйтеся існуючого стилю та шаблонів коду.
