**Bank Statement Parser** es una biblioteca Python de código abierto que analiza extractos bancarios de seis formatos (CAMT.053, PAIN.001, CSV, OFX, QFX, MT940) en pandas DataFrames estructurados. Todo el procesamiento se ejecuta localmente: cero llamadas de red, salida determinista y redacción automática de PII.

## Comience en segundos

```bash
pip install bankstatementparser
```

```python
from bankstatementparser import create_parser, detect_statement_format

fmt = detect_statement_format("statement.xml")
parser = create_parser("statement.xml", fmt)
df = parser.parse()  # pandas DataFrame, ready to use
```

## Una biblioteca, seis formatos

Analice CAMT.053, PAIN.001, CSV, OFX, QFX y MT940 en pandas DataFrames estructurados con una única API unificada. No es necesario instalar paquetes separados para cada formato.

| Característica | Analizador de extractos bancarios | OSS de formato único (mt940, ofxparse) | SaaS (Ocrolus, Parseur) |
|---|---|---|---|
| Formatos soportados | 6, API unificada | 1 cada uno | Muchos (a través de OCR) |
| Privacidad de datos | 100% local, cero llamadas de red | 100% locales | Datos enviados externamente |
| Costo | Gratis, Apache 2.0 | Gratis | $49-$1,000+/mes |
| redacción de información personal | Integrado, activado de forma predeterminada | No | Varía |
| Transmisión | Memoria limitada | No | N / A |
| seguridad postal | Endurecimiento incorporado | No | N / A |
| Deduplicación | Incorporado con puntuaciones de confianza | No | Alguno |

## Creado para la migración ISO 20022

SWIFT ha establecido plazos firmes: todas las instituciones financieras deben recibir CAMT.053 antes de noviembre de 2027, y MT940/MT942/MT950 se retirarán por completo en noviembre de 2028. Bank Statement Parser maneja los formatos MT940 heredado e ISO 20022 moderno (CAMT.053, PAIN.001) en una única API, por lo que su proceso de análisis funciona durante la transición y más allá.

## Actuación

- **Más de 27.000 transacciones/segundo** para el análisis CAMT.053
- **52.000+ transacciones/segundo** para el análisis de PAIN.001
- **< 2 ms** tiempo hasta el primer resultado
- **Memoria constante** de 1K a 50K+ transacciones vía streaming
- **467 pruebas** con cobertura de sucursales del 100% en Python 3.9 a 3.14

## ¿Por qué el analizador de extractos bancarios?

- **Detección automática de formato**:`detect_statement_format()`identifica archivos automáticamente y`create_parser()`devuelve el analizador correcto.
- **Privacidad primero**: la redacción de PII está activada de forma predeterminada. Los campos confidenciales (nombres, IBAN, direcciones) están enmascarados en la salida CLI. Optar por`--show-pii`cuando sea necesario.
- **Listo para producción**: ingesta segura de ZIP (protección contra bombas, rechazo de entradas cifradas), validación de entradas y prevención de cruce de rutas.
- **Salida flexible**: exporte a CSV, JSON, Excel o convierta a Polars DataFrames.
- **Procesamiento paralelo**: analiza varios archivos simultáneamente con`parse_files_parallel()`.


## Construido para la producción

Bank Statement Parser está diseñado para equipos de tesorería, desarrolladores de tecnología financiera y funcionarios de cumplimiento que procesan datos financieros confidenciales. La biblioteca se utiliza en procesos de migración de MT940 a CAMT, sistemas de conciliación automatizados y flujos de trabajo de auditoría regulatoria en instituciones financieras.

- **467 pruebas** con cobertura de sucursales del 100% en Python 3.9 a 3.14
- **Dependencias con bloqueo hash SHA-256** con CycloneDX SBOM para cada versión
- **Salida determinista**: una entrada idéntica produce resultados de bytes idénticos en cada ejecución.
- **Apache 2.0 con licencia**: uso gratuito en sistemas comerciales e internos
