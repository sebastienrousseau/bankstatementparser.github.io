**Bank Statement Parser** は、6 つの形式 (CAMT.053、PAIN.001、CSV、OFX、QFX、MT940) の銀行取引明細書を構造化パンダ データフレームに解析するオープンソースの Python ライブラリです。すべての処理はローカルで実行されます。ネットワーク呼び出しはなく、確定的な出力が行われ、PII は自動的に編集されます。

## 数秒で始められます

```bash
pip install bankstatementparser
```

```python
from bankstatementparser import create_parser, detect_statement_format

fmt = detect_statement_format("statement.xml")
parser = create_parser("statement.xml", fmt)
df = parser.parse()  # pandas DataFrame, ready to use
```

## 1 つのライブラリ、6 つのフォーマット

CAMT.053、PAIN.001、CSV、OFX、QFX、MT940 を単一の統合 API で構造化されたパンダ データフレームに解析します。形式ごとに個別のパッケージをインストールする必要はありません。

| 特徴 | 銀行取引明細書パーサー | 単一フォーマット OSS (mt940、ofxparse) | SaaS (Ocrolus、Parseur) |
|---|---|---|---|
| サポートされている形式 | 6、統一API | 各1個 | 多数 (OCR 経由) |
| データプライバシー | 100% ローカル、ネットワーク通話なし | 100%地元産 | 外部に送信されるデータ |
| 料金 | 無料、Apache 2.0 | 無料 | $49～$1,000+/月 |
| PII 編集 | 内蔵、デフォルトでオン | いいえ | さまざま |
| ストリーミング | 境界のあるメモリ | いいえ | 該当なし |
| ZIPセキュリティ | 内蔵硬化 | いいえ | 該当なし |
| 重複排除 | 信頼性スコアを内蔵 | いいえ | いくつかの |

## ISO 20022 移行用に構築

SWIFT は明確な期限を設定しています。すべての金融機関は 2027 年 11 月までに CAMT.053 を受け取る必要があり、MT940/MT942/MT950 は 2028 年 11 月までに完全に廃止されます。Bank Statement Parser は、従来の MT940 形式と最新の ISO 20022 形式 (CAMT.053、PAIN.001) の両方を単一の API で処理するため、解析パイプラインは移行中および移行後も機能します。

＃＃ パフォーマンス

- **CAMT.053 解析の場合、**27,000+ トランザクション/秒**
- **52,000+ トランザクション/秒** (PAIN.001 解析の場合)
- **< 2 ms** 最初の結果が得られるまでの時間
- **定メモリ** ストリーミング経由で 1,000 から 50,000 以上のトランザクションに対応
- **467 のテスト**、Python 3.9 から 3.14 までの 100% のブランチ カバレッジ

## なぜ銀行取引明細書パーサーなのか?

- **フォーマットの自動検出**:`detect_statement_format()`ファイルを自動的に識別し、`create_parser()`正しいパーサーを返します。
- **プライバシー第一**: PII 編集はデフォルトでオンになっています。機密フィールド (名前、IBAN、アドレス) は、CLI 出力ではマスクされます。オプトインする`--show-pii`必要なときに。
- **本番対応**: 安全な ZIP 取り込み (爆弾保護、暗号化されたエントリの拒否)、入力検証、およびパス トラバーサル防止。
- **柔軟な出力**: CSV、JSON、Excel にエクスポートするか、Polars DataFrame に変換します。
- **並列処理**: 複数のファイルを同時に解析します。`parse_files_parallel()`.


## 実稼働用に構築

Bank Statement Parser は、機密の財務データを処理する財務チーム、フィンテック開発者、コンプライアンス担当者向けに設計されています。このライブラリは、MT940 から CAMT への移行パイプライン、自動調整システム、金融機関全体の規制監査ワークフローで使用されます。

- **467 のテスト**、Python 3.9 から 3.14 までの 100% のブランチ カバレッジ
- 各リリースの CycloneDX SBOM を使用した **SHA-256 ハッシュロックされた依存関係**
- **確定的出力** — 同一の入力が実行ごとにバイト同一の結果を生成します
- **Apache 2.0 ライセンス** — 商用システムおよび社内システムで自由に使用できます
