Vi välkomnar bidrag från utvecklare, tekniska skribenter och alla som är intresserade av att förbättra analysen av kontoutdrag för finansvärlden.

## Hur man bidrar

### Rapportera problem

Hittade du en bugg eller har du en funktionsbegäran? [Öppna ett problem på GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). Vänligen inkludera:

- En tydlig beskrivning av problemet eller förslaget.
- Steg för att reproducera (för buggar).
- Din Python-version och ditt operativsystem.

### Skicka kod

1. Dela [förrådet](https://github.com/sebastienrousseau/bankstatementparser).
2. Skapa en funktionsgren (`git checkout -b feature/your-feature`).
3. Skriv tester för dina ändringar (vi kräver 100 % filialtäckning).
4. Kör testsviten:`pytest`.
5. Skicka in en pull-förfrågan med en tydlig beskrivning.

### Förbättra dokumentationen

Förbättringar av dokumentation är alltid välkomna. Du kan:

- Åtgärda stavfel eller förtydliga befintligt innehåll.
- Lägg till nya användningsexempel i [exempelkatalogen](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- Förbättra docstrings i källkoden.

## Utvecklingsinställningar

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## Kodstandarder

- Alla koder måste passera`ruff`ludd och`mypy`typkontroll.
- Alla åtaganden måste undertecknas.
- Alla pull-förfrågningar måste behålla 100 % filialtäckning.
- Följ befintlig kodstil och mönster.
