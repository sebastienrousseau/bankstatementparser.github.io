हम डेवलपर्स, तकनीकी लेखकों और वित्त समुदाय के लिए बैंक स्टेटमेंट पार्सिंग को बेहतर बनाने में रुचि रखने वाले किसी भी व्यक्ति के योगदान का स्वागत करते हैं।

## योगदान कैसे करें

### रिपोर्ट मुद्दे

कोई बग मिला या कोई सुविधा अनुरोध है? [GitHub पर एक मुद्दा खोलें](https://github.com/sebastienrousseau/bankstatementparser/issues). कृपया शामिल करें:

- समस्या या सुझाव का स्पष्ट विवरण.
- पुनरुत्पादन के चरण (बग्स के लिए)।
- आपका पायथन संस्करण और ऑपरेटिंग सिस्टम।

### कोड सबमिट करें

1. फोर्क करें [भंडार](https://github.com/sebastienrousseau/bankstatementparser).
2. एक फीचर शाखा बनाएं (`git checkout -b feature/your-feature`).
3. अपने परिवर्तनों के लिए परीक्षण लिखें (हमें 100% शाखा कवरेज की आवश्यकता है)।
4. परीक्षण सूट चलाएँ:`pytest`.
5. स्पष्ट विवरण के साथ पुल अनुरोध सबमिट करें।

### दस्तावेज़ीकरण में सुधार करें

दस्तावेज़ीकरण सुधारों का हमेशा स्वागत है। तुम कर सकते हो:

- टाइप संबंधी त्रुटियां ठीक करें या मौजूदा सामग्री को स्पष्ट करें।
- [उदाहरण निर्देशिका] में नए उपयोग के उदाहरण जोड़ें(https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- सोर्स कोड में डॉकस्ट्रिंग्स में सुधार करें।

## विकास सेटअप

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## कोड मानक

- सभी कोड पास होने चाहिए`ruff`लिंटिंग और`mypy`टाइप चेकिंग.
- सभी प्रतिबद्धताओं पर हस्ताक्षर होना चाहिए।
- सभी पुल अनुरोधों को 100% शाखा कवरेज बनाए रखना होगा।
- मौजूदा कोड शैली और पैटर्न का पालन करें।
