**요약:** 은행 명세서 구문 분석기는 6가지 은행 명세서 형식(CAMT.053, PAIN.001, CSV, OFX, QFX, MT940)을 pandas DataFrames로 구문 분석하는 오픈 소스 Python 라이브러리입니다. 100% 로컬 처리, 기본적으로 PII 수정, 27K+ tx/s 처리량.

Bank 명세서 Parser는 6가지 형식의 은행 명세서를 구조화된 Pandas DataFrame으로 구문 분석하는 오픈 소스 Python 라이브러리입니다. 모든 처리는 로컬에서 이루어집니다. 즉, 네트워크 호출이 없고 결정적 출력이 이루어지며 자동 PII 수정이 이루어집니다.

## 이것은 누구를 위한 것인가요?

- 전환 중에 이전 형식과 새 형식을 모두 처리하는 파서가 필요한 MT940에서 CAMT.053으로 마이그레이션하는 **재무팀**.
- mt940 + ofxparse + 사용자 정의 CSV 논리를 함께 연결하는 대신 단일 종속성을 원하는 조정, 보고 또는 회계 파이프라인을 구축하는 **핀테크 개발자**.
- 기본적으로 PII 수정 및 외부 서비스로 데이터를 전송하지 않는 감사 준비가 된 결정적 출력이 필요한 **규정 준수 팀**.
- 로컬 오픈 소스 도구를 사용하여 민감한 금융 데이터를 제3자 SaaS로 전송하는 것을 거부하는 **모든 사람**.

## 지원되는 형식

| 체재 | 기준 | 파일 유형 | 파서 클래스 |
|---|---|---|---|
| CAMT.053 | ISO 20022 은행-고객 명세서 | `.xml` | `CamtParser` |
| 고통.001 | ISO 20022 학점 이전 개시 | `.xml` | `Pain001Parser` |
| CSV | 일반 은행 수출 | `.csv` | `CsvStatementParser` |
| OFX | 개방형 금융거래소 | `.ofx` | `OfxParser` |
| QFX | 금융교류를 촉진하다 | `.qfx` | `QfxParser` |
| MT940 | SWIFT 표준 | `.mt940`, `.sta` | `Mt940Parser` |

모든 형식은 일관된 열 이름을 사용하여 정규화된 Pandas DataFrame을 생성하므로 다운스트림 처리가 형식에 구애받지 않게 됩니다.

## 주요 기능

- **형식 자동 감지**:`detect_statement_format()`형식을 식별합니다.`create_parser()`올바른 파서를 인스턴스화합니다.
- **스트리밍 구문 분석**: 제한된 메모리를 사용하여 대용량 파일(50MB+, 50K+ 트랜잭션)을 처리합니다.`parse_streaming()`.
- **병렬 처리**: 여러 파일을 동시에 구문 분석합니다.`parse_files_parallel()`ProcessPoolExecutor를 사용합니다.
- **중복 제거**: 설명 가능한 신뢰도 점수를 통해 정확한 중복 항목과 의심되는 일치 항목을 감지합니다.
- **메모리 내 구문 분석**:`from_string()`그리고`from_bytes()`디스크 I/O가 없는 SFTP 및 API 워크플로용.
- **보안 ZIP 처리**:`iter_secure_xml_entries()`압축 비율 제한, 항목 크기 제한 및 암호화된 항목 거부 기능이 있습니다.
- **내보내기**: CSV, JSON, Excel(`.xlsx`) 및 선택적인 Polars DataFrames.

## 보안 및 개인정보 보호

- **PII 수정**: 이름, IBAN 및 주소는 기본적으로 CLI 출력에서 ​​마스킹됩니다. 다음으로 선택`--show-pii`.
- **XXE 보호**: XML 구문 분석을 사용합니다.`resolve_entities=False`, `no_network=True`, `load_dtd=False`.
- **ZIP 폭탄 보호**: 압축률 제한(기본값 100:1), 항목 크기 제한(10MB), 암호화된 항목 거부.
- **경로 탐색 방지**: 위험한 패턴 차단 목록 및 심볼릭 링크 해결.
- **공급망 보안**: SHA-256 해시 잠금 종속성, CycloneDX SBOM, 빌드 출처 증명.
