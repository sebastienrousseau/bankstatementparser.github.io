## Bi o ṣe le ṣe alabapin

### Awọn ọrọ Iroyin

Ti ri kokoro kan tabi ni ibeere ẹya kan? [Ṣi ọrọ kan lori GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). Jọwọ fi sii:

- Apejuwe ti o daju ti iṣoro tabi imọran.
- Awọn igbesẹ lati tun ṣe (fun awọn idun).
- Ẹya Python rẹ ati ẹrọ ṣiṣe.

### Fi koodu

1. Fork [ibi ipamọ](https://github.com/sebastienrousseau/bankstatementparser).
2. Ṣẹda ẹka ẹya kan (`git checkout -b feature/your-feature`).
3. Kọ awọn idanwo fun awọn ayipada rẹ (a nilo 100% agbegbe agbegbe).
4. Ṣiṣe awọn suite igbeyewo:`pytest`.
5. Fi kan fa ìbéèrè pẹlu kan ko o apejuwe.

### Ṣe ilọsiwaju iwe

Awọn ilọsiwaju iwe jẹ itẹwọgba nigbagbogbo. O le:

- Fix typos tabi ṣe alaye akoonu ti o wa tẹlẹ.
- Ṣafikun awọn apẹẹrẹ lilo tuntun si [itọsọna apẹẹrẹ](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- Ṣe ilọsiwaju awọn docstrings ni koodu orisun.

## Eto Idagbasoke

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```
