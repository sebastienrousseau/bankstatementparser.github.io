우리는 개발자, 기술 작가 및 금융 커뮤니티를 위한 은행 명세서 구문 분석 개선에 관심이 있는 모든 사람의 기여를 환영합니다.

## 기여 방법

### 문제 신고

버그를 발견했거나 기능 요청이 있으십니까? [GitHub에서 문제 열기](https://github.com/sebastienrousseau/bankstatementparser/issues). 다음을 포함해 주세요:

- 문제나 제안에 대한 명확한 설명.
- 재현 단계(버그의 경우).
- Python 버전 및 운영 체제.

### 코드 제출

1. [저장소](https://github.com/sebastienrousseau/bankstatementparser).
2. 기능 브랜치를 생성합니다(`git checkout -b feature/your-feature`).
3. 변경 사항에 대한 테스트를 작성합니다(100% 분기 적용 범위가 필요함).
4. 테스트 스위트를 실행합니다:`pytest`.
5. 명확한 설명과 함께 풀 요청을 제출하세요.

### 문서 개선

문서 개선은 언제나 환영합니다. 다음을 수행할 수 있습니다.

- 오타를 수정하거나 기존 콘텐츠를 명확히 합니다.
- [예제 디렉터리](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- 소스 코드의 독스트링을 개선합니다.

## 개발 설정

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## 코드 표준

- 모든 코드가 통과되어야 함`ruff`보풀과`mypy`유형 검사.
- 모든 커밋은 서명되어야 합니다.
- 모든 끌어오기 요청은 100% 분기 적용 범위를 유지해야 합니다.
- 기존 코드 스타일과 패턴을 따릅니다.
