银行对账单解析器

您的隐私对我们很重要。

＃＃ 介绍

银行对账单解析器（“我们”、“我们”、“我们的”）是一个开源 Python 库。本隐私政策解释了当您访问我们的网站bankstatementparser.com 时我们如何收集和使用信息。

银行对账单解析器库本身会在您的计算机上本地处理所有数据。任何财务数据、个人数据或银行对账单内容都不会传输到我们的服务器或任何第三方。

我们收集的信息

网站分析

我们使用以下分析服务来了解访问者如何使用我们的网站：

  • Google Analytics 4（测量 ID：G-FL9DEBFHN1）——收集匿名使用数据，包括访问的页面、网站停留时间和推荐来源。谷歌分析使用cookie。请参阅[Google 的隐私政策](https://policies.google.com/privacy）。
  • Microsoft Clarity - 记录匿名会话重播，包括鼠标移动、单击和滚动，以帮助我们改善用户体验。 Clarity 不收集个人数据。请参阅微软的隐私声明.

联系表

如果您提交我们的联系表格（由 Formspree 提供支持），我们会收集您的姓名、电子邮件地址和消息内容。该数据由 Formspree 处理并根据其隐私政策.

我们不收集的数据

  • 我们不收集或处理任何银行对账单数据。
  • 除了上述分析服务之外，我们不会使用 cookie 进行广告或跟踪。
  • 我们不会出售、出租或与第三方分享您的个人信息。
  • 我们不收集付款信息。

GDPR 规定您的权利

如果您位于欧洲经济区 (EEA) 或英国，您拥有以下权利：

  • 访问权 -- 索取我们持有的有关您的数据的副本。
  • 纠正权 -- 请求纠正不准确的数据。
  • 删除权 -- 请求删除您的个人数据。
  • 限制处理的权利 - 要求我们限制我们使用您的数据的方式。
  • 数据可移植性的权利 -- 以机器可读的格式请求您的数据。
  • 反对权 -- 反对处理您的个人数据。

要行使任何这些权利，请使用本页底部的联系方式。

数据保留

  • 分析数据 根据 Google 和 Microsoft 的标准保留期限进行保留（Google Analytics 为 14 个月，Microsoft Clarity 会话记录为 30 天）。
  • 提交的联系表单将保留一段时间以回复您的询问，然后删除。

饼干

本网站使用以下 cookie：

曲奇饼 提供者 目的 期间
_嘎，嘎* 谷歌分析 分析跟踪 2年

您可以在浏览器设置中禁用 cookie。该网站将在没有 cookie 的情况下继续运行。

儿童隐私

我们的网站和图书馆不针对 16 岁以下的儿童。我们不会故意收集儿童的个人数据。

本政策的变更

我们可能会不时更新本隐私政策。更改将发布在此页面上并附有更新日期。最后更新时间：2026 年 4 月。
