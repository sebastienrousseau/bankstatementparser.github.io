**은행 명세서 파서**는 6가지 형식(CAMT.053, PAIN.001, CSV, OFX, QFX, MT940)의 은행 명세서를 구조화된 Pandas DataFrame으로 구문 분석하는 오픈 소스 Python 라이브러리입니다. 모든 처리는 로컬에서 실행됩니다. 즉, 네트워크 호출이 없고 결정적 출력이 이루어지며 자동 PII 수정이 이루어집니다.

## 몇 초 안에 시작하세요

```bash
pip install bankstatementparser
```

```python
from bankstatementparser import create_parser, detect_statement_format

fmt = detect_statement_format("statement.xml")
parser = create_parser("statement.xml", fmt)
df = parser.parse()  # pandas DataFrame, ready to use
```

## 하나의 라이브러리, 여섯 가지 형식

단일 통합 API를 사용하여 CAMT.053, PAIN.001, CSV, OFX, QFX 및 MT940을 구조화된 Pandas DataFrame으로 구문 분석합니다. 각 형식마다 별도의 패키지를 설치할 필요가 없습니다.

| 특징 | 은행 명세서 파서 | 단일 형식 OSS(mt940, ofxparse) | SaaS(Ocrolus, Parseur) |
|---|---|---|---|
| 지원되는 형식 | 6, 통합 API | 각 1개 | 다수(OCR을 통해) |
| 데이터 개인정보 보호 | 100% 로컬, 네트워크 호출 없음 | 100% 현지 | 외부로 전송된 데이터 |
| 비용 | 무료, 아파치 2.0 | 무료 | $49-$1,000+/월 |
| PII 수정 | 내장, 기본적으로 켜져 있음 | 아니요 | 다양함 |
| 스트리밍 | 제한된 메모리 | 아니요 | 해당 없음 |
| 우편번호 보안 | 내장 경화 | 아니요 | 해당 없음 |
| 중복 제거 | 신뢰도 점수 내장 | 아니요 | 일부 |

## ISO 20022 마이그레이션을 위해 구축됨

SWIFT는 확고한 기한을 정했습니다. 모든 금융 기관은 2027년 11월까지 CAMT.053을 수신해야 하며, MT940/MT942/MT950은 2028년 11월까지 완전히 폐기됩니다. 은행 거래 내역서 파서는 단일 API에서 레거시 MT940과 최신 ISO 20022 형식(CAMT.053, PAIN.001)을 모두 처리하므로 구문 분석 파이프라인은 전환 기간과 그 이후에도 작동합니다.

## 성능

- CAMT.053 구문 분석의 경우 **초당 27,000개 이상의 트랜잭션**
- PAIN.001 구문 분석의 경우 **52,000개 이상의 트랜잭션/초**
- **< 2ms** 첫 번째 결과까지 걸리는 시간
- 스트리밍을 통한 1,000개에서 50,000개 이상의 트랜잭션까지 **고정 메모리**
- Python 3.9부터 3.14까지 100% 분기 적용 범위를 갖춘 **467개 테스트**

## 왜 은행 명세서 파서인가?

- **형식 자동 감지**:`detect_statement_format()`파일을 자동으로 식별하고`create_parser()`올바른 파서를 반환합니다.
- **개인 정보 보호 우선**: PII 수정이 기본적으로 켜져 있습니다. 민감한 필드(이름, IBAN, 주소)는 CLI 출력에서 ​​마스킹됩니다. 다음으로 선택`--show-pii`필요할 때.
- **생산 준비됨**: 보안 ZIP 수집(폭탄 방지, 암호화된 항목 거부), 입력 유효성 검사 및 경로 통과 방지.
- **유연한 출력**: CSV, JSON, Excel로 내보내거나 Polars DataFrames로 변환합니다.
- **병렬 처리**: 여러 파일을 동시에 구문 분석합니다.`parse_files_parallel()`.


## 생산용으로 제작됨

은행 명세서 파서는 민감한 재무 데이터를 처리하는 재무팀, 핀테크 개발자 및 규정 준수 담당자를 위해 설계되었습니다. 이 라이브러리는 MT940에서 CAMT로의 마이그레이션 파이프라인, 자동화된 조정 시스템, 금융 기관 전반의 규제 감사 워크플로우에 사용됩니다.

- Python 3.9부터 3.14까지 100% 분기 적용 범위를 갖춘 **467개 테스트**
- 모든 릴리스에 대해 CycloneDX SBOM이 포함된 **SHA-256 해시 잠금 종속성**
- **결정적 출력** — 동일한 입력은 실행될 때마다 바이트와 동일한 결과를 생성합니다.
- **Apache 2.0 라이센스** — 상업용 및 내부 시스템에서 자유롭게 사용
