## Highlights ⭐️

* **Every release asset checksummed**: the notes' Checksums section now lists `SHA256SUMS` itself and every signature, certificate and provenance file, the gap that held up the 0.0.35 audit.
* **Signed releases with SLSA provenance**: the archive, SBOM and `SHA256SUMS` are signed with keyless cosign, and SLSA Build Level 3 provenance (`.intoto.jsonl`) ships alongside them.
* **More of the gate in CI**: Markdown and README lint, ruff lint and format, a coverage floor, `npm audit` and `pip-audit` on locked tooling, and Atheris fuzzing of the front-matter validator, with the site built by `ssg` 0.0.77.
* **In lockstep with the suite's 0.0.36 release**: bankstatementparser.com ships 0.0.36 with core and its satellite packages.
