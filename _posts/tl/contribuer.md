Tinatanggap namin ang mga kontribusyon mula sa mga developer, teknikal na manunulat, at sinumang interesado sa pagpapabuti ng pag-parse ng bank statement para sa komunidad ng pananalapi.

## Paano Mag-ambag

### Mag-ulat ng Mga Isyu

Nakahanap ng bug o may kahilingan sa tampok? [Magbukas ng isyu sa GitHub](https://github.com/sebastienrousseau/bankstatementparser/issues). Mangyaring isama ang:

- Isang malinaw na paglalarawan ng problema o mungkahi.
- Mga hakbang sa pagpaparami (para sa mga bug).
- Ang iyong bersyon ng Python at operating system.

### Isumite ang Code

1. I-fork ang [repository](https://github.com/sebastienrousseau/bankstatementparser).
2. Gumawa ng feature branch (`git checkout -b feature/your-feature`).
3. Sumulat ng mga pagsubok para sa iyong mga pagbabago (nangangailangan kami ng 100% saklaw ng sangay).
4. Patakbuhin ang test suite:`pytest`.
5. Magsumite ng pull request na may malinaw na paglalarawan.

### Pagbutihin ang Dokumentasyon

Ang mga pagpapabuti ng dokumentasyon ay palaging malugod na tinatanggap. Maaari mong:

- Ayusin ang mga typo o linawin ang umiiral na nilalaman.
- Magdagdag ng mga bagong halimbawa ng paggamit sa [direktoryo ng mga halimbawa](https://github.com/sebastienrousseau/bankstatementparser/tree/main/examples).
- Pagbutihin ang mga docstring sa source code.

## Pag-setup ng Pag-unlad

```bash
git clone https://github.com/sebastienrousseau/bankstatementparser.git
cd bankstatementparser
python3 -m venv .venv && source .venv/bin/activate
pip install poetry && poetry install --with dev
pytest  # Run the test suite
```

## Mga Pamantayan ng Code

- Dapat pumasa ang lahat ng code`ruff`linting at`mypy`pagsuri ng uri.
- Lahat ng commit ay dapat pirmahan.
- Dapat mapanatili ng lahat ng pull request ang 100% branch coverage.
- Sundin ang umiiral na istilo at pattern ng code.
